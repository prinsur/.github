# Prinsur

Human Powered, AI Amplified.

We build realtime conversation tools from Taiwan. The person stays in charge of
the conversation. The AI works alongside them, supplying context and prompts
only where they actually help.

## saidtrack

A purpose-driven copilot for live conversations. You declare an objective before
you start, something like "convince this interviewer I can do the job", and
saidtrack transcribes the room in realtime while surfacing only the suggestions
that move that objective forward.

Everything it produces is private to you. The other side never sees it. It fits
interviews, sales calls, discovery sessions and negotiations alike.
